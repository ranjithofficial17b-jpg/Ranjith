# Sales Insights & Analytics Dashboard

## 📌 Project Overview

Sales Insights & Analytics is a data analysis project developed to analyze sales, revenue, profit, products, and regional performance using Excel, Power BI, and Python.

## 🎯 Project Objective

- Analyze overall sales performance
- Calculate sales, cost, profit, and profit margin
- Identify top-performing products
- Analyze regional performance
- Analyze monthly sales and profit trends
- Create interactive dashboards

📊 Dataset

The dataset contains **500 sales transaction records** with the following columns:

- Date
- Salesperson
- Region
- Product
- Category
- Quantity
- Unit Price
- Cost

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power BI
- Python
- Pandas
- NumPy
- Matplotlib

## 🔍 Analysis Performed

- Data Cleaning
- Gross Sales Calculation
- Total Cost Calculation
- Profit Calculation
- Profit Margin Analysis
- Monthly Sales Analysis
- Monthly Profit Analysis
- Top 5 Products Analysis
- Regional Sales Performance

## 📈 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Profit Margin KPI
- Monthly Sales Trend
- Regional Sales Performance
- Top 5 Products by Sales
- Monthly Profit Analysis
- Region Filter
- Product Filter
- Category Filter
- Month Filter

## 🏆 Key Insights

- **Laptop Pro 15** was the highest-selling product.
- **West Region** recorded the highest sales.
- Product analysis identified the top-performing products.
- Monthly analysis helped identify sales and profit trends.
- Interactive filters allow users to analyze specific regions, products, categories, and months.
